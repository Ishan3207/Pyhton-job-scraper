# Internship Scraper thing

A simple Python tool to find internships on LinkedIn without logging in. It scrapes job listings based on your role and location preferences and saves them to a text and CSV file.

How to Use  setup

1. Install Python
Make sure you have Python installed on your computer.

2. Download the Code
Clone this repository by using
git clone https://github.com/Ishan3207/Pyhton-job-scraper in yout terminal in a location where you want it to be intalled

3. Install Dependencies
Open your terminal/command prompt in this folder and run:
pip install selenium beautifulsoup4 webdriver-manager

4. Runing the Code
open the folder that you just dowloaded
there open your terminal and run "python scraper.py"
Follow the Prompts
    Enter Role (e.g., "Data Analyst")
    Enter Location (e.g., "Remote")
    Enter Number of Jobs (e.g., 50)

the output will be saved as both a csv and txt file in the same folder
